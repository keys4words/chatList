# Исправление ошибки "unable to open database file"

## Проблема

После установки приложения через инсталлятор возникала ошибка:
```
unable to open database file
```

Это происходило потому, что приложение пыталось создать базу данных в директории установки (Program Files), где нет прав на запись.

## Решение

Создан модуль `app_paths.py`, который автоматически определяет правильное место для хранения данных:

- **Для установленной версии**: `%LOCALAPPDATA%\ChatList\`
- **Для режима разработки**: текущая директория

## Изменения

1. **app_paths.py** - новый модуль для определения путей
2. **db.py** - обновлен для использования правильного пути к БД
3. **logger.py** - обновлен для использования правильного пути к логам
4. **models.py, network.py, prompt_improver.py, init_db.py** - обновлены для загрузки .env из правильного места

## Пересборка приложения

После исправлений нужно пересобрать приложение:

```powershell
# 1. Соберите исполняемый файл
.\build.ps1

# 2. Соберите установщик
.\build_installer.ps1
```

## Расположение данных после установки

После установки все данные приложения будут храниться в:
```
C:\Users\<USERNAME>\AppData\Local\ChatList\
```

В этой директории будут:
- `chatlist.db` - база данных
- `logs/` - директория с логами
- `.env` - файл с API-ключами (если создан пользователем)

## Проверка

После пересборки и установки:
1. Установите приложение
2. Запустите его
3. Проверьте, что в `%LOCALAPPDATA%\ChatList\` создались файлы
4. Приложение должно запускаться без ошибок

## Примечание

При первом запуске установленной версии приложение автоматически создаст необходимые директории и файлы в AppData.
