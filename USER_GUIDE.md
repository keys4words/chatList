# Руководство пользователя ChatList

## Начало работы

### Первый запуск

1. **Установите зависимости:**
   ```powershell
   pip install -r requirements.txt
   ```

2. **Создайте файл `.env`** в корне проекта с вашими API-ключами:
   ```
   OPENAI_API_KEY=sk-...
   OPENROUTER_API_KEY=sk-or-v1-...
   DEEPSEEK_API_KEY=sk-...
   GROQ_API_KEY=gsk_...
   ```

3. **Инициализируйте базу данных** (опционально):
   ```powershell
   python init_db.py
   ```
   Это добавит примеры моделей в базу данных.

4. **Запустите приложение:**
   ```powershell
   python main.py
   ```

## Основные операции

### Отправка запроса

1. Введите ваш промт в текстовое поле в верхней части окна
2. (Опционально) Добавьте теги через запятую в поле "Теги"
3. Нажмите кнопку **"Отправить запрос"**
4. Дождитесь получения ответов от всех активных моделей
5. Результаты появятся в таблице ниже

### Работа с результатами

- **Просмотр результатов:** Все ответы отображаются в таблице с колонками: Модель, Ответ, Выбрать
- **Выбор результатов:** Отметьте чекбоксы у нужных результатов
- **Сохранение:** Нажмите **"Сохранить выбранные"** для сохранения в базу данных
- **Экспорт:** Нажмите **"Экспорт"** для сохранения текущих результатов в файл (Markdown или JSON)
- **Очистка:** Нажмите **"Очистить"** для удаления всех результатов из таблицы

### Работа с промтами

#### Сохранение промта
1. Введите промт и теги
2. Нажмите **"Сохранить промт"**
3. Промт будет доступен в выпадающем списке "Сохраненные промты"

#### Выбор сохраненного промта
1. Откройте выпадающий список "Сохраненные промты"
2. Выберите нужный промт
3. Промт загрузится в текстовое поле
4. Можете отредактировать и отправить

#### Поиск промтов
- Используйте поле "Поиск" рядом со списком промтов для быстрого поиска
- Или используйте меню **"Промты" → "Поиск промтов..."** для расширенного поиска

## Управление моделями

### Добавление модели

1. Откройте меню **"Модели" → "Управление моделями..."**
2. Нажмите кнопку **"Добавить"**
3. Заполните форму:
   - **Название:** Имя модели (например, `openai/gpt-4` для OpenRouter)
   - **API URL:** URL API для запросов
   - **API ID:** Имя переменной из `.env` файла (например, `OPENROUTER_API_KEY`)
   - **Тип модели:** Выберите тип (openai, deepseek, groq, openrouter)
   - **Активна:** Отметьте, если модель должна использоваться при отправке запросов
4. Нажмите **"Сохранить"**

### Редактирование модели

1. Откройте **"Модели" → "Управление моделями..."**
2. Выберите модель в таблице
3. Нажмите **"Редактировать"**
4. Внесите изменения
5. Нажмите **"Сохранить"**

### Активация/деактивация модели

1. Откройте **"Модели" → "Управление моделями..."**
2. Выберите модель в таблице
3. Нажмите **"Активировать/Деактивировать"**
4. Модель изменит свой статус активности

### Удаление модели

1. Откройте **"Модели" → "Управление моделями..."**
2. Выберите модель в таблице
3. Нажмите **"Удалить"**
4. Подтвердите удаление

## Экспорт данных

### Экспорт текущих результатов

1. После получения результатов нажмите **"Экспорт"**
2. Выберите формат (Markdown или JSON)
3. Выберите место сохранения файла
4. Файл будет сохранен

### Экспорт всех сохраненных результатов

1. Откройте меню **"Файл" → "Экспорт результатов..."**
2. Выберите формат (Markdown или JSON)
3. Выберите место сохранения файла
4. Все сохраненные результаты будут экспортированы

## Поиск результатов

1. Откройте меню **"Результаты" → "Поиск результатов..."**
2. Введите поисковый запрос
3. Просмотрите найденные результаты

## Логирование

Все запросы к API автоматически логируются в папку `logs/`. 

- Логи сохраняются по дням (один файл на день)
- Формат: `chatlist_YYYYMMDD.log`
- Логи содержат информацию о запросах, ответах и ошибках

## Примеры использования

### Пример 1: Сравнение ответов разных моделей

1. Введите промт: "Объясни квантовую физику простыми словами"
2. Добавьте теги: "физика, образование"
3. Нажмите "Отправить запрос"
4. Сравните ответы разных моделей в таблице
5. Выберите лучшие ответы и сохраните их

### Пример 2: Работа с OpenRouter

1. Добавьте API-ключ OpenRouter в `.env`:
   ```
   OPENROUTER_API_KEY=sk-or-v1-...
   ```

2. Добавьте модель через интерфейс управления:
   - Название: `openai/gpt-4`
   - API URL: `https://openrouter.ai/api/v1/chat/completions`
   - API ID: `OPENROUTER_API_KEY`
   - Тип: `openrouter`

3. Используйте модель как обычно - она появится в списке активных моделей

### Пример 3: Экспорт для документации

1. Отправьте запрос и получите результаты
2. Выберите нужные результаты
3. Нажмите "Экспорт" → выберите "Markdown"
4. Сохраненный файл можно использовать в документации

## Советы и рекомендации

1. **Используйте теги** для организации промтов по категориям
2. **Сохраняйте важные промты** для повторного использования
3. **Экспортируйте результаты** для дальнейшего анализа
4. **Проверяйте логи** при возникновении проблем с API
5. **Деактивируйте неиспользуемые модели** для ускорения работы
6. **Используйте поиск** для быстрого нахождения нужных промтов и результатов

## Решение проблем

### Нет активных моделей

- Откройте **"Модели" → "Управление моделями..."**
- Убедитесь, что хотя бы одна модель активна
- Проверьте, что API-ключи добавлены в `.env`

### Ошибки при отправке запросов

- Проверьте правильность API-ключей в `.env`
- Убедитесь, что модель активна
- Проверьте логи в папке `logs/` для деталей ошибок

### База данных не создается

- Убедитесь, что у приложения есть права на запись в текущей директории
- Проверьте, что нет других процессов, использующих базу данных

## Поддержка

При возникновении проблем:
1. Проверьте логи в папке `logs/`
2. Убедитесь, что все зависимости установлены
3. Проверьте правильность API-ключей
4. Запустите тесты: `python test_app.py`
