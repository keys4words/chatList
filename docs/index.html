🚀 Quick Start

1. Install ChatList

Download and run the installer, or use the standalone executable.

2. Configure API Keys

Create a .env file in the application directory:

OPENAI_API_KEY=sk-your-key-here OPENROUTER_API_KEY=sk-or-v1-your-key-here DEEPSEEK_API_KEY=sk-your-key-here GROQ_API_KEY=gsk_your-key-here

3. Add Models

Use "Models" → "Manage Models..." to add and configure AI models.

4. Start Comparing

Enter a prompt, select active models, and click "Send Request" to compare responses!
