# Инструкция по созданию установщика ChatList

## Требования

1. **Python 3.11+** - для запуска скриптов генерации
2. **Inno Setup 6** - для создания установщика Windows
   - Скачать можно с официального сайта: https://jrsoftware.org/isdl.php
   - Рекомендуется установить Inno Setup 6 или новее

## Процесс создания установщика

### Автоматический способ (рекомендуется)

#### Windows PowerShell:
```powershell
.\build_installer.ps1
```

#### Windows Command Prompt:
```cmd
build_installer.bat
```

Скрипт автоматически:
1. Соберет исполняемый файл через PyInstaller
2. Сгенерирует `setup.iss` с актуальной версией из `version.py`
3. Создаст установщик через Inno Setup

### Ручной способ

1. **Соберите исполняемый файл:**
   ```powershell
   .\build.ps1
   ```
   или
   ```cmd
   build.bat
   ```

2. **Сгенерируйте setup.iss:**
   ```powershell
   python generate_setup.py
   ```

3. **Создайте установщик:**
   - Откройте Inno Setup Compiler
   - Откройте файл `setup.iss`
   - Нажмите "Build" → "Compile" (или F9)
   - Установщик будет создан в папке `installer/`

## Структура установщика

### Установка
- Устанавливает программу в `C:\Program Files\ChatList\`
- Создает ярлыки в меню "Пуск"
- Опционально создает ярлык на рабочем столе
- Включает файлы: `ChatList-v{version}.exe`, `README.md`, `LICENSE`

### Удаление (Uninstall)
При удалении программы автоматически удаляются:
- Все файлы программы
- Директория `logs/` с логами
- Файл базы данных `chatlist.db`
- Все `.log` файлы в директории установки
- Пустая директория установки

### Версия
Версия установщика берется из файла `version.py` (переменная `__version__`).

## Настройка установщика

Для изменения параметров установщика отредактируйте файл `generate_setup.py`:
- `MyAppPublisher` - имя издателя
- `MyAppURL` - URL проекта
- `DefaultDirName` - директория установки по умолчанию
- И другие параметры в секции `[Setup]`

## Результат

После успешной сборки установщик будет находиться в папке `installer/`:
- `ChatList-Setup-v{version}.exe` - установщик программы

## Примечания

- Установщик требует права администратора для установки
- Поддерживаются русский и английский языки интерфейса установщика
- Иконка установщика берется из файла `app.ico`
- Лицензия отображается из файла `LICENSE`
